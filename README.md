# 原点

一个私密、本地、键盘驱动的思维展开器。打开后直接从中心主题开始，用 `Tab` 和 `Enter` 快速铺开结构，不需要账号、知识库或云端服务。

![原点主界面](docs/design/origin-browser-final.jpg)

## 当前能力

- 从左到右的稳定树形自动布局
- 键盘创建、导航、提升层级、重排、折叠和删除节点
- 统一命令注册表与 `⌘K` 命令面板
- 最近 100 次结构/文本操作的撤销与重做
- 节点搜索与定位
- CommonMark/GFM Markdown 渲染、整图/分支复制与结构化粘贴
- 可保存到指定目录、重新打开并继续编辑的 `.md` 工作文件
- 独立 Markdown 草稿、最近五张图快速切换、另存为及当前文件自动恢复
- Markdown 自动保存、原子替换、去重备份与本地画布状态恢复
- 鼠标/触控板平移、缩放、适应内容与聚焦节点
- 空白画布框选、Shift/Command 增减选择与批量删除、复制、折叠
- 分支拖到空白处成为浮动分支，再拖到节点上重新归入层级
- Tauri 2 macOS 桌面外壳
- 可配置的全局快捷键唤醒并聚焦主窗口

## 运行

```bash
npm install
npm run desktop:dev
```

只运行浏览器开发版本：

```bash
npm run dev
```

构建 macOS 应用与 DMG：

```bash
npm run desktop:build
```

当前产物用于本机运行，采用本地临时签名，尚未使用 Apple Developer 证书签名或公证；分发到其他 Mac 前需要补正式签名与 notarization。

## 高频快捷键

| 操作 | 快捷键 |
| --- | --- |
| 创建同级节点 | `Enter` |
| 创建子节点 | `Tab` |
| 提升一级 | `Shift+Tab` |
| 编辑节点 | 直接输入或按空格 |
| 完成编辑 / 节点内换行 | `Enter` / `Shift+Enter` |
| 删除节点及子树 | `Delete` 或 `Backspace` |
| 选择父/子/同级节点 | 方向键 |
| 扩展选择 | `Shift` + 方向键 |
| 全选可见节点 / 清除选择 | `⌘A` / `Esc` |
| 复制 / 剪切 / 粘贴节点与分支 | `⌘C` / `⌘X` / `⌘V` |
| 框选 / 平移画布 | 空白拖动 / `Space` + 拖动 |
| 浮动 / 重新归入分支 | 拖动节点到空白处 / 拖到目标节点 |
| 移动同级顺序 | `⌘↑` / `⌘↓` |
| 折叠或展开 | `⌘/` |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z` |
| 搜索节点 | `⌘F` |
| 打开文件 / 立即保存 / 另存为 | `⌘O` / `⌘S` / `⇧⌘S` |
| 复制当前分支为 Markdown | `⇧⌘C` |
| 打开命令面板 | `⌘K` |
| 全局唤醒应用 | 默认 `⇧⌘M`，可在“更多”中修改 |

画布处于节点选择状态时，以上组合键操作节点和文档；编辑节点文字、
文档标题或搜索词时，`⌘A`、`⌘C`、`⌘X`、`⌘V` 保持系统原生文本行为。

每次新建都会立即生成一份独立的本地 Markdown 草稿，不弹出路径选择；标题
旁的切换入口显示当前文档之外最近编辑的五张图，底部可以打开任意其他文件。
新建或切换前会先确保当前图已经持久化，失败时停留在原画布，不丢弃内容。
连续发起新建、打开或导入时以最后一次操作为准，较早完成的读取不会反向覆盖
当前画布。关闭窗口会先保存再隐藏，`⌘Q` 会先保存最新修改再退出；保存失败时
应用保持可见。
“另存为”是创建其他位置文件的唯一入口：应用内草稿会在新文件校验成功后移动
到新位置，用户目录中的文件则保留原件并切换到新文件。最近编辑中的应用内草稿
也可以直接使用“移动到…”整理位置，不需要先打开。
应用会记住最后打开的 Markdown，并在文件内容没有被外部修改时恢复折叠与
画布位置。绑定文件若被其他编辑器修改、移动或删除，自动保存会立即停止并
保留外部版本，可选择“另存为”保留应用内修改。内容变化前保留上一份
Markdown，字节完全相同的重复保存不会占用备份槽。

嵌套列表形式的 Markdown 是默认、可持续编辑的工作文档。普通 CommonMark
与 GFM 文档中的标题、段落、列表、任务、代码块和表格都可以渲染成思维导图；
无法准确映射成树的内容会作为包含原文的普通节点留在画布上，可以直接编辑、
删除或拖动。丰富结构打开为未绑定副本，保存时另存为新的 Markdown，不会
覆盖原文件；即使在另存面板中重新选择原路径也会被阻止，且不增加额外的检查
面板。旧 `.mindmap.json` 仍可打开作为恢复
或迁移备份，但不再作为默认工作格式。

同一张图始终保留一个主原点。拖到空白画布的分支会成为可独立定位的浮动
分支，但仍属于同一文档；它在 Markdown 中只是另一个顶层列表项，所以不依赖
原点也能阅读和修改。浮动位置保存在本地画布状态中；没有这份状态时，应用会
为顶层分支安排默认位置，而不会丢失层级内容。

在空白根节点中粘贴多行 Markdown 会直接生成整张导图；在画布选择状态下
粘贴则添加到当前节点。

## 开发回归检查

```bash
npm run check:regression
```

这项检查覆盖前端测试、网页构建和 Rust 测试，只是开发回归结果，不代表产品、
业务、视觉或体验验收。涉及桌面打包、窗口、文件、快捷键或剪贴板的改动，还要
由 Agent 在新构建的应用上运行：

```bash
npm run check:desktop-runtime
```

桌面真实流程仍需按改动风险检查连续状态，例如“编辑 A → 切换或新建 B →
继续编辑 B”，不能用彼此独立的 A、B 单点测试代替。最终报告分开给出开发回归、
桌面真实流程和用户体验验收，不使用一个合并的“全部绿灯”。

产品与交互模型见 [`docs/product-model.md`](docs/product-model.md)，视觉概念见 [`docs/design/origin-primary-screen.png`](docs/design/origin-primary-screen.png)。
