# Laniakea：产品与交互模型

## 用户与任务

- 用户是已经掌握需求分析方法的个人创作者、产品或工程人员。
- 核心任务是接到问题后立即写下原点，并用键盘连续展开三层以上的结构。
- 这是前台工作台；诊断、存储实现、Agent 流程和产品说明不进入主界面。

## 页面与流程

产品只有一个持续工作的编辑器外壳；根层与每个下层 Space 都是独立的整屏工作层，
低频调用和一次性选择使用按需出现的临时覆盖层：

1. 思维导图画布：选择、编辑、创建、重排、折叠、缩放与平移。
2. 节点对象菜单：只在右键明确调用时出现；没有子 Space 时提供“下钻为…”，
   已有子 Space 时只提供进入或删除。
3. Space 类型选择：创建前在中央覆盖层选择“思维图”或“流程”。
4. Map Space：一张新的、持久的思维图画布，以父节点主题初始化中心节点并继续发散。
5. Flow Space：从一个思维节点进入，以步骤、判断与有向连线组成一张轻量自由流程画布。
6. 搜索覆盖层：跨根思维图、Map Space 与 Flow Space 定位内容。
7. 命令面板：发现和执行低频命令。
8. 桌面版唤醒快捷键设置：录入并验证一个全局组合键；网页版不显示。

打开应用会恢复最后使用的文档；新建、打开、导入和另存为都回到同一编辑器，
不建立首页、知识库或文件管理后台。标题旁的切换器显示当前文档之外最近编辑的
五张图，并在底部提供“打开文件…”。文档内容与编辑行为跨平台一致，只有持久化
载体和平台专属操作不同。

## 平台与数据模型

- 页面级操作对象是一份 Laniakea 文档。根 Space 始终是思维图；任一思维节点可以
  锚定一个 Map Space 或 Flow Space。同一视口同一时刻只编辑一种视觉语法，不把流程原地混入
  父思维图，也不把 Space 误称为同一数据的视图切换。
- “下钻”是创建并进入下一交互层级的动作，不是“流程”的别名。类型只在创建时
  选择一次，此后不可转换；已有 Space 只能进入或删除，删除后才可重新创建其他类型。
  Map 与 Flow 都是持久对象，都整屏替换当前工作层，并通过同一个返回路径恢复父层
  选择与视口。父层不会把下层画布原地展开成第二套编辑器；它把下层 Space 表示为
  从锚点延伸出的概要子节点，概要可选择、移动、复制或删除，但不成为正文节点。
- 桌面版把文档绑定到 Markdown 文件路径，并在应用数据目录保存画布辅助状态。
- 网页版把文档绑定到浏览器文档 ID，使用 IndexedDB 保存多张图和完整视图状态。
- 网页版在文档库底部常驻说明“内容保存在此浏览器”，并在首次保存完成后以
  临时消息确认；空闲画布不常驻保存文案，也不暗示云同步或文件下载。
- Markdown 始终是可带走的单文档格式；网页版同时提供包含全部文档和视图状态的
  完整备份。恢复完整备份时作为安全的新副本导入，不覆盖现有浏览器文档。
- 普通标题和列表继续承担根思维图；Map 与 Flow 的可携带语义放在一个带 `version` 的
  `laniakea` fenced block 中，并用当前大纲结构 ref 锚定父节点。步骤坐标、缩放与
  选择不进入这个区块。区块缺损、版本未知、锚点失效或内部关系不完整时，整份来源
  降级为受保护的 rich Markdown，不允许静默覆盖。
- 浏览器清除站点数据、无痕模式和更换浏览器是明确的数据边界；产品不建立账号、
  云数据库或同步冲突系统。
- 支持 File System Access API 的浏览器可以直接写入用户选择的 Markdown；
  其他浏览器保留文件输入和下载，不把实验能力作为唯一通路。
- 同一张浏览器文档使用递增版本防止多个标签页静默覆盖；旧标签页保存时保留
  较新版本，并允许把自己的内容下载为 Markdown。

兼容性边界：`com.openadam.origin` 应用标识、`origin://` 内部事件名、
`origin.*` 浏览器存储键以及 `origin-` 恢复文件前缀来自早期版本。它们不是当前
展示品牌，但为了让既有安装继续读取原数据而保持稳定；除非另有迁移方案，不要
把这些内部标识当作遗漏的品牌文案批量改名。

## 桌面文件操作边界

- `.md` 是默认工作文档；每次“新建”立即在应用草稿目录生成一份独立的
  Markdown，不弹出路径选择。用户需要整理位置时再使用“另存为”。
- 切换或新建前必须完成当前文档的持久化；尚未绑定路径的恢复稿或导入副本先
  转为独立 Markdown 草稿。保存失败时停留在当前画布，不执行切换。
- 新建、打开和导入共享同一份切换代次；较新的用户动作出现后，较早的
  文件读取、激活或草稿准备即使稍后完成，也不能替换当前画布或启动文档。
- 最近文档只保存路径、标题和最后打开时间等索引信息，正文始终以 Markdown
  文件为准；当前文档不在最近列表中重复出现。
- 文档标题通常使用一级标题；精确的“未命名思维”是临时占位而非永久名称。
  打开已有文件时，占位标题优先解析为有意义的文件名，其次才是主原点；新建空白稿
  第一次提交非空主原点时同步确定标题，之后编辑主原点不会覆盖已经明确的标题。
  主原点与浮动分支都使用普通的顶层列表项，分支内部继续使用嵌套列表，保证普通
  编辑器仍可直接阅读和修改。
- 折叠、视口与稳定节点状态保存在应用数据目录的本地缓存中，并用 Markdown
  内容摘要校验；外部修改文件后缓存自动失效，以文件内容为准。
- 根思维图、Map Space 和 Flow Space 各自记住视口；进入下层时还会记住父层选择和
  交互目标。普通往返恢复原位置，不重新自动居中；新建 Space 后首次返回例外地适应一次
  新的父层全图，让主主题、锚点与新概要同时可见，此后仍由用户视口控制。Space 内容变化重写 Markdown；仅 Space 视口变化
  只更新辅助状态，不占用正文备份或制造外部内容冲突。
- 已绑定的 Markdown 被其他编辑器修改、移动或删除后，应用停止覆盖并显示
  可见失败状态；用户可以另存应用内版本，外部版本保持不变。
- CommonMark/GFM 的标题、段落、列表、任务、代码块与表格都能生成导图。
  只有纯大纲子集允许原位自动保存；丰富 Markdown 作为未绑定副本打开，必须
  另存为新的 Markdown，避免格式或内容被静默改写。另存对话框默认建议不同
  文件名，底层按规范化路径禁止选择原丰富 Markdown 作为目标。
- 无法准确映射为树的 Markdown 块直接成为包含原文的普通画布节点，沿用现有
  编辑、删除、拖动和撤销能力；不增加侧边检查面板、特殊提示或额外对象类型。
- 用户只看到一个“另存为”操作，不再区分“导出副本”。当前文件是应用内草稿时，
  成功写入并校验新位置后移动绑定并清理旧草稿；当前文件已在用户目录时，保留
  原文件并切换到新文件。两种情况都不要求用户理解存储来源。
- 最近编辑里的应用内草稿提供“移动到…”；可直接整理到用户目录，不必先打开，
  成功前始终保留原草稿。用户目录里的文件继续提供“在访达中显示”和“复制路径”。
- `.mindmap.json` 只用于兼容旧文件和桌面恢复，打开后不会覆盖原备份。网页
  完整备份使用带有明确格式版本的 Laniakea JSON 容器。
- 空白根节点粘贴多行 Markdown 会替换空白稿并生成整张图；普通画布粘贴仍
  追加到主选节点。
- 画布上的 `Command+V` 直接消费系统原生粘贴事件携带的文本，不再次请求读取
  剪贴板，也不出现需要二次点击的 Paste 授权浮窗。普通单行文本创建一个子节点；
  单行 Markdown 列表项会去掉 `- `、`* ` 或序号标记，多行大纲继续按层级粘贴。
- 保存失败、打开失败、另存失败和移动失败使用同一个紧凑反馈载体，不用静默成功或增加
  常驻说明。用户主动点击“保存”或按 `Command+S` 时，成功后也通过这个载体短暂确认
  “已保存”；后台自动保存成功仍然保持安静。
- Markdown 正文一旦完成原子替换就视为已提交；随后画布状态或旧备份清理失败
  作为非致命提醒返回，并继续使用本次正文摘要，避免下次保存误报外部冲突。
- macOS 当前为保证原子替换，会在目标文件同目录创建临时文件并同步目录；Downloads
  等受保护目录因此可能触发系统“文件与文件夹”授权。这项授权不能靠退回直接覆盖来
  消除。开发构建使用临时签名，重建后权限身份可能变化；稳定发行签名与未来若采用
  单文件安全书签/系统协调替换是两条独立的交付设计，开发绿灯不代表授权体验完成。
- macOS 关闭按钮由前端在保存成功后隐藏窗口；`Command+Q` 首次请求退出时由
  原生层阻止退出，待前端完成最新文档保存后才批准退出。保存失败时窗口保持可见。

## 产品对象

- 文档：标题、根思维 Space、节点锚定的子 Space、格式版本与各自的本地视图状态。
- 思维节点：文本、父节点、有序子节点、可选子 Space、折叠状态和时间戳。
- Map Space：锚定思维节点、独立的中心节点与树、浮动分支和画布视口。
- Flow Space：锚定思维节点、类型化步骤、语义转移、可选本地位置和独立视口。
- Flow 节点：`start | step | decision | end`、文本与时间戳；边表达下一步和可选分支标签。
  `start` 与 `end` 是兼容旧文档和显式标注需要的可选端点，不是创建流程的强制模板。
- Flow 语义、位置和交互仍由 Laniakea 拥有；当前节点位置与真实测量作为固定布局输入，
  矩形边界端口、正交避障路线、视图诊断和变化契约由 `@openadam/graph-view-compiler` 编译，
  圆角路径和交叉桥仍由同一确定性几何内核计算。该包不读取 Markdown、
  不保存视口，也不调用 Agent。
- 选择：一个主节点与一组按导图顺序排列的可见节点；决定结构命令和批量命令的作用目标。
- 画布交互目标：在思维节点与下层 Space 概要代理之间显式二选一。它与普通节点选择
  共用画布焦点和选择入口，但决定当前可用命令与风险策略；概要代理必须同时绑定锚点
  与具体 Space 身份，过期目标不能回退成普通节点操作。
- 下钻选择：一次临时的创建类型选择，只在没有子 Space 的单个节点上明确调用后存在；
  关闭时不改内容，确认创建后类型成为不可变属性。
- 编辑会话：当前草稿；Enter 确认、Shift+Enter 换行、Esc 放弃。
- 历史：最近 100 次结构或文本变更；支持撤销和重做。

## 可见组件与复用规则

- 悬浮工具组：根层左侧只承载文档标题与最近文档切换入口；进入 Map 或 Flow 后，
  同一胶囊增加返回、当前节点与 Space 类型。右侧仍只承载文档级操作。
- 画布：每次只渲染当前 Space 的统一视口、SVG 连线和 HTML 节点。
- 节点：主原点、浮动分支根、一级节点、普通节点四个明确变体。
- 单选思维节点只改变选择高亮，不自动出现工具条、按钮或解释。`Tab`、`Enter`、
  `Shift+Enter`、`Command+Enter` 和直接输入继续承担高频发散：依次创建子节点、
  下方同级、上方同级、包裹当前分支的新父节点和直接编辑；选择本身不能被当成
  打开低频功能的意图。插入父节点时当前节点和后代保持原结构，新节点精确替换当前
  节点在原父级中的位置；主原点和浮动根也原位包裹，不让整棵分支突然漂移。
- 节点右键先打开对象菜单；没有子 Space 时菜单只暴露“下钻为…”，再进入中央类型
  选择层。键盘 `Shift+F10` 或命令面板中的“下钻当前节点…”可直接进入同一选择层。
  选择层以大图标卡片提供“思维图”和“流程”，先选择、再确认创建；关闭不改变画布。
  已有子 Space 时不再显示类型选择，只能进入或删除，不能把 Flow 转为 Map 或反向转换。
- 有子 Space 的父节点本身不显示角标；同一关系线上延伸一个独立的概要子节点，并参与
  排版、折叠和连线。Map 概要只列中心节点的前三个直接子节点，更多内容另起一行显示
  `...`，不展开第四项或更深后代；Flow 概要排除 `start` / `end`，最多直接列前三步，
  四步时完整显示，超过四步时显示 `前三步...→最后一步`。概要悬停、聚焦或选中时显示
  进入角标；点击概要只选择，双击概要或点击角标进入完整 Space。
- 概要节点是下层 Space 的父层操作代理，不写入普通 Markdown 大纲，也不成为 Agent
  可写节点。复制得到当前概要文字；拖到无子 Space 的普通节点会把整张 Space 改挂到
  新锚点；删除仅删除该 Space 并保留父节点，提交前必须经过二次确认且可撤销。
  概要选中时，`Enter` 进入下层图，`Command+C` 复制概要，`Command+X` 复制后请求删除，
  `Backspace/Delete` 请求删除，`←` 返回所属思维节点；`Tab`、`Shift+Enter`、
  `Command+Enter` 等结构创建操作不可用，也不出现在命令面板。快捷键先按交互目标解析
  为语义稳定的操作，不能把普通节点的“创建同级”操作在概要上改解释为“进入”。
- Map 与 Flow 都是独立语义 Space。进入任一层都会
  保存父层选择与视口，`Esc`、返回按钮或路径返回上层。
  若指针正在执行拖动、框选、平移、连线或重连，第一次 `Esc` 只取消当前直接操作并
  留在本层；操作结束后的下一次 `Esc` 才返回上层。
- Flow 不强制生成开始与结束节点；新建流程只以锚点内容生成一个普通步骤。画布左侧保留
  只含“步骤 / 判断 / 起止”的小型图形栏，图形既可点击放到当前视野，也可拖到画布后
  按网格和相邻节点中心线吸附。`start`、`end` 继续兼容旧文档，但只是可自由添加、改字、
  连线和删除的椭圆图形，不承担流程合法性约束；它们略小于普通步骤而不缩成难读角标。
  节点悬停或键盘聚焦时出现上、右、下、左四个
  方向点，点击即在该方向创建并连接一个普通步骤；节点可以直接拖动重排。普通单选再
  出现一条紧凑工具条，以“步骤 / 判断”直接创建对应节点，连线入口拖到已有节点即可
  建立转移，多个来源可以汇入同一目标，低频改类型、删除和搜索汇合收到“更多”。拖动
  期间只有可连接目标显示轻提示，命中目标后预览吸附；松开提交，`Esc`、
  失焦、页面隐藏、指针取消或落在无效位置都不改内容。连接只拒绝自连和同方向重复连接；
  用户明确画出的返回线和循环可以保留。删除节点只删除该节点与附着连线，不替用户猜测
  前后节点是否应当接通；删除最后一个节点后保留可继续放图形的空白画布。
  已有连线使用横平竖直的圆角折线，互不相关的线相交时在横线绘制跨线桥；点击连线后只
  显示起点与终点两个拖拽柄，可把任一端拖到同一节点的另一侧或其他合法节点，直接更新
  `fromPort` / `toPort`，取消或无效落点保持原连接。
  连线和方向快捷创建只建立用户明确画出的关系，不会因为第二条出线而偷偷改变源节点
  图形或自动补写分支文字。
  `Enter` 添加下一步，`Tab` 添加或扩充分支，方向键按画布方向移动选择；右键菜单与
  “汇合到已有步骤”选择层保留为低频、键盘和大图搜索后备。分支线标签在画布上直接
  编辑，编辑框透明无边框，只显示文字、选区和光标；没有人工位置的旧流程先按拓扑
  自动布局，首次四向创建或拖动时冻结当前可见位置，再进入自由排布。位置只属于本地
  画布状态，不进入 Markdown 的可携带流程语义。
- 节点内容与空状态提示分离：新建思维导图和键盘新建节点都以空内容进入编辑；
  主原点在编辑与非编辑状态都显示“中心主题”，其他空节点都显示“输入文本”。
  提交空内容后仍保存为空，不把提示文字或“未命名节点”写进文档。
- 当前所有可见的新建节点入口都会立即进入该节点的编辑状态；导入和粘贴创建
  节点时已经携带真实文本。因此第一版不维护“子主题 1、2、3”自动编号或缺号
  补位规则，避免为不可达状态增加一套与 Markdown 内容竞争的命名系统。
- 节点宽度随当前可见文字自适应，空内容由提示文字与左右内边距共同撑起，
  不再设置额外最小宽度。主原点只响应用户输入的显式换行，不自动折行；其他
  节点达到更宽的角色上限后自动换行并随行数增高。
- 主原点与一级分支保留 48px 的单行强调高度；二级节点使用 44px，三级及以下
  使用更紧凑的 36px，并同步收紧到 13px 字号与 14px 左右留白。多行时仍按实际行数和上下内边距
  自然增高，层级差异不能靠牺牲正文可读性或裁切实现。
- 显示态和编辑态共享同一个垂直居中表面，原生文本框只承载文字、光标与输入；
  画布使用裁切而非原生滚动容器，聚焦编辑框不得改变节点或文字位置。主原点文字
  保持居中；其他节点显示、编辑和拖拽预览统一左对齐，单行因内容自适应仍保持紧凑，
  自动折行或显式换行后从同一左边缘连续阅读。
- 中文输入法组词期间冻结节点外框和画布布局，但临时扩展文本编辑表面以同时显示
  已有文字与拼音预编辑串；候选上屏后再按最终文字统一重排，不能以隐藏已有上下文
  来换取边框稳定。
- 后代节点的横坐标由父节点当前实际宽度加固定层级间距推导，不再按深度写死。
  父节点变宽时整棵后代分支同步向右移动，父子节点边缘之间的连线长度保持稳定。
- 分支拖放：非主原点分支只有在越过防误触距离并落到明确空白区域后才成为
  可独立定位的浮动分支；进入有效节点朝向子节点一侧的磁性范围时，从候选
  上级向拖动分支显示一条淡色关系预览线，线条的垂直落点同时表达它在现有
  子节点中的插入顺序，松手后按该位置成为子节点；拖回同一父节点时使用同一
  规则完成同级重排，和 `Command+↑/↓` 共用有序子节点模型。高密度区域中多个
  有效父级磁性范围重叠时，原父级优先完成同级重排；只有拖出原父级有效范围、
  明确进入其他节点范围后才改变父级，不能逼用户改用快捷键来躲避误吸附。浅层节点使用
  稍宽的前向范围；拖动分支位于候选背后或大面积重叠时不吸附。只记录浮动
  分支根的位置，分支内部仍使用自动布局；拖动不足、拖到自身或后代上都保持
  原结构。拖动中按 `Esc`、窗口失焦、页面隐藏、文档切换或指针捕获丢失都取消
  本次操作并保留原结构；取消后的松手不能再次提交。
- 普通分支、Space 概要、Map 框选/平移以及 Flow 节点、连线、重连、图形栏和视口平移
  共用一个宿主中断入口，统一处理 `Esc`、窗口失焦、页面隐藏和捕获释放；Flow 拖动的
  边缘自动平移也必须同时停止。各操作仍保留自己的阈值、候选几何、预览、提交和撤销
  策略，不用对象类型分支伪装成一个大而全的拖动实现。直接操作期间滚轮不得改变其
  起始视口。
- 当拖动从当前多选中的节点开始时，操作对象是去除主原点并消除祖先/后代重复后的
  全部选中根分支。整组在预览和提交中保持画布相对位置；落到空白处时一起成为浮动
  分支，落到有效父节点时按当前导图顺序作为连续子节点块插入。整组移动、重排或
  吸附只产生一次历史记录并保持多选；按下未选中的节点则先切换为该节点单选再拖动。
- 折叠单个分支时，所有一级分支保留折叠前的画布纵向锚点，只隐藏并重新排布
  更深层后代，避免一次信息收起带动主干跳动；展开时优先保持被展开分支的锚点，
  空间不足时再把相邻分支向外推开。批量折叠与文档首次布局仍使用紧凑自动布局。
- 框选：空白画布拖动按节点中心点命中；Shift 追加，点击空白或 Esc 清除。编辑节点时
  点击空白先提交当前文字，再进入没有任何节点被选中的状态。
- 浮动控件：细指针桌面不常驻缩放面板，使用触控板、`Command` 加 `+/-` 与
  `Command+0` 控制；缩放时立即临时显示当前比例，最小、100% 与最大比例附带
  关键标识，随后柔和淡出。“适应内容”按当前已提交布局计算，并可临时进入低于
  日常编辑下限的“全图”概览；从概览继续放大时连续过渡，不跳回编辑下限。粗指针
  设备保留缩小、100%、放大和适应内容按钮。
  左下角只在打开或保存超过一秒、失败、首次浏览器保存确认及操作消息出现时
  展开；内容先淡出，外框随后收起。失败状态保持可见并提供恢复操作。删除、
  剪切和粘贴可直接点击“撤销”，也继续支持 `Command+Z`。
- 覆盖层：搜索与命令共享同一弹层骨架和键盘关闭规则。搜索输入使用光标和局部图标
  变化表达键盘焦点，不复用画布对象的紫色选中环。最近文档的文件操作子菜单位于可滚动
  列表之外并相对触发项定位，靠近窗口边缘时回避裁切；滚动列表时关闭旧子菜单。
- 视口的最后控制权属于用户的直接平移和缩放。键盘方向导航、搜索结果跳转或显式
  “聚焦选中节点”可揭示新目标，但已选中或正在编辑的节点不能因为文字重排、保存视口、
  布局刷新或组件重渲染持续把画布拉回；手动移出视口后必须保持用户留下的位置。

## 视觉系统

- 冷白画布、石墨文字、深紫主色；一级分支仅用紫、蓝、绿、琥珀作结构识别。
  分支色位于连线末端并以贴住节点外边框的方头短竖线收束；选中或编辑时短线
  隐藏，只保留统一的紫色焦点环。
- 无侧栏、无卡片仪表盘、无渐变和装饰插画。
- 节点使用发丝边框、8–12px 圆角和只在焦点状态出现的轻阴影。
- 控件与文档文字分开设定字号，确保画布内容和应用框架各自清晰。

## 多选与画布手势

- 空白画布拖动用于框选，节点边缘擦过选框不会误选。
- `Shift` 或 `Command` 点击用于增减单个节点；`Command+A` 选择全部可见节点。
- 画布选择状态下，`Command+C/X/V` 复制、剪切、直接粘贴完整节点分支；粘贴到
  主选节点下，不再弹出二次确认。
- 文本编辑、文档标题与搜索输入中，`Command+A/C/X/V` 保持 macOS 原生文本行为。
- `Space` 按住并拖动用于平移；单独轻按仍进入当前单选节点的编辑。
- 多选支持一次删除、复制 Markdown、折叠、展开、拖动与吸附；一次批量内容变化对应
  一次撤销。选中集合包含祖先与后代时只移动最外层根，后代随其子树一起移动。
- 创建、编辑和键盘提升层级只在单选时可用；`Command+↑/↓` 只重排单个节点，拖动
  重排与吸附则作用于当前多选根分支块。
- 选择是编辑器状态，不进入文档文件；折叠后不可见的后代不会被框选或全选。
- 浮动分支仍属于同一文档并参与搜索、全选、复制、删除、撤销和自动保存；
  主原点不可拖离，避免同一文档出现多个语义不明的中心节点。
