# Laniakea 图标

图标以深靛色为底，四条金色流线在视觉中心汇聚。曲线保持不对称的自然走势，
在图标边缘延续出画；细光丝、克制的光晕与少量星点表达超星系团的意象。
主轮廓在 favicon 和桌面小图标尺寸仍应清晰，不能用大量星点或耀斑淹没汇聚点。

- `artwork.png`：1254 × 1254 的满幅位图原稿，由图像生成工具沿原有金色流线设计修订。
- `app-icon.png`：1024 × 1024 RGBA 生产母版，汇聚点居中，含圆角与透明外留白。
- `app-icon-maskable.png`：同一母版的深靛底版本，供 PWA 系统裁切。

运行 `npm run build:icons` 可从原稿重建全部资源。脚本以原稿中的汇聚点为裁切中心，
统一生成留白、圆角和透明度，再使用仓库已有的 Tauri CLI 导出桌面图标、网页 favicon、
Apple touch icon 和 PWA 图标。临时 SVG 仅承担位图裁切与蒙版，不是矢量重绘。
图像生成服务只用于制作原稿，复现图标导出不需要该服务。

替换原稿时，应同步检查脚本的原稿尺寸与汇聚点位置，并实际查看 32、64、128 像素
和桌面尺寸；旧图标保留在 Git 历史中。Tauri 生成其他平台资源不代表新增平台运行支持。

背景参考：[Laniakea 可视化制作说明](https://blogs.nature.com/blog/under-the-covers-nature-revealed-4-september-2014/)。
参考的流线表达星系速度场；本图标为艺术抽象，不是科学数据图。
