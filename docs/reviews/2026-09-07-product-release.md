# 0.3.5 产品交付复核

本次从 `03e9c91` 的当前源码、浏览器和独立标识的桌面应用检查，保留已经批准的
A 图标。目标是完成可交付的本地思维导图与下钻流程；最终业务与体验验收仍由用户决定。

## 初始发现与修复

- macOS WebKit 中，新建中心主题的占位字换行并滚到最后一个字，还出现重复焦点框。
  根节点编辑保持单行，保留外层选中提示；新构建实际显示完整“中心主题”。
- 五节点流程“适应内容”重复计算画布留白，缩到约 66.5%；手动移走节点还会保留
  原自动布局的空范围。现在按实际节点和连线范围适配，浏览器同一流程为 100%，
  桌面实际流程也清晰可读。连线绕行范围仍参与适配。
- 恢复写入者身份仍有 `Math.random` 分支，被 CodeQL 标记。改用已有安全随机 ID
  路径，并测试只提供 `getRandomValues` 时两个写入者的独立身份。
- Web 与 macOS 包缺少完整依赖许可载体。按实际 Web 打包模块和锁定的 macOS
  Cargo 依赖图生成许可与归属文本；缺失的上游文本以版本、提交、摘要绑定补充。
  构建校验实际应用包的图标、许可与来源清单字节。开发和回归入口也生成这些资源，
  不依赖上一次构建留下的忽略文件。
- 包版本统一到 0.3.5；README 更新实际流程截图、入口和 Agent/桌面/网页边界。

## 本次验证

- 开发回归：68 个前端测试文件、606 项测试，55 项 Rust 测试；Web/MCP 构建、
  插件许可、发布卫生、真实 stdio 与 40 轮并发更新检查通过。
- 浏览器真实顺序：多层输入 → 下钻流程 → 步骤和判断分支 → 返回 → 搜索跳转 →
  编辑 → 撤销/重做 → 重载；切换两份文档；760 × 560 下搜索和跳转。
- 浏览器真实双窗口：较新版本保存后，旧窗口继续编辑触发持久冲突入口；保留副本后
  再次重载，两份修改分别保留，没有覆盖较新文档。
- 新构建桌面：输入 → 原生另存为 Markdown → 子节点仍在编辑时立即退出 → 重启，
  正文与磁盘都保留未结束编辑的文字。
- 桌面外部修改冲突：磁盘写入新版本 → 旧窗口继续编辑 → 明确提示原文件未覆盖 →
  另存新文件，逐字核对两份文件各自保留内容。
- 桌面下钻：键盘创建步骤与判断分支 → 适应内容 → 返回上层 → 退出保存。
- 本次新增期望依据是实际故障与现有产品要求：短流程保持可读、只计算实际对象、
  写入者独立、分发包保留依赖文本。图标缓存版本依据已批准的 A 图标替换。

完整回归在一次与构建同时运行时遇到组件异步加载超时；保持原断言，单独重跑相关
流程及完整回归通过。没有放宽超时或修改快照来取得绿灯。

## 发布边界

可以推进源码、网页版和本机安装。公开宣传限于已实现的本地编辑、下钻与 Markdown
交接。Agent 可修改根图；下层图和流程只有有界只读预览。没有云同步、协作或手机端
完整编辑承诺，也不宣称桌面会自动合并外部文件修改。

本次并未逐一穷尽所有快捷键、输入法、剪贴板、设备及系统版本。桌面测试使用独立
应用数据与测试文件；工具的剪贴板注入失败不作为产品通过或失败的证据。

公共 DMG 需要 Developer ID 签名、公证、Gatekeeper 验证。当前环境没有有效签名
身份和发布凭据，故该项阻塞；本地临时签名构建不能替代公共下载验收。
